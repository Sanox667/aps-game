# Монтажник АПС

2D-аркада про монтажника пожарной сигнализации. Курсирует по объектам, прокладывает
кабельные трассы от распаячных коробок, ставит извещатели и сирены, гонится за
дедлайном смены, а каждые пять объектов принимает генподрядчик. С уровнями
открываются новые инструменты и способности.

## Играть

**https://sanox667.github.io/aps-game/** — GitHub Pages, работает на компе и на телефоне.

Локально (для разработки):

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
# http://127.0.0.1:8123/
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Ходить | `←` `→` или `A` `D` |
| Лестницы | `↑` `↓` или `W` `S` |
| Проложить кабель | `C` или `Q` |
| Установить оборудование | `Пробел` или `E` |
| Сдать работы (приёмка) | `Пробел` у щита АПС |
| Звук вкл/выкл | `M` |
| Следующий объект | `Enter` |
| Начать заново | `R` |

На телефоне дублируют экранные кнопки (лево/право, лестницы, «Кабель», «Ставить»).

## Геймплей

- **Кабели — базовая механика.** Устройство нельзя смонтировать, пока от распаячной
  коробки этажа к точке монтажа не проложена светящаяся трасса. За кабель тоже
  начисляются очки.
- **Дедлайн смены.** У каждого объекта своё время. Полоска в HUD; последние 10 секунд —
  красный пульс и тиканье. Просрочка: −40 очков, комбо в ноль, сердитый генподрядчик.
- **Объекты идут по кругу из 10 сцен** с ростом сложности: БЦ «Заря» → Школа №14
  (темно) → Склад «Гранит» (5 этажей, ящики) → ТЦ «Меридиан» → Стадион «Факел» (босс) →
  Больница «Надежда» → Офис «Синева» → Завод «Прогресс» → Аэропорт «Крыло» →
  Энергоблок «Аврора» (босс). Со 2-го круга каждого объекта таймеры короче,
  босс быстрее и ловит дальше, штраф поимки растёт.
- **Босс «Генподрядчик» каждые 5 объектов.** Патрулирует этажи с планшетом, ловит
  вас: −15 очков и стан. Финал — приёмка: гонка к щиту АПС. Доехал первым: −30;
  вы сдали раньше: +130.
- **Комбо** за быстрые установки — множитель до x2. Рация из 4-й смены делает комбо
  несгораемым.
- **Разблокировки**: 2 шуруповёрт · 3 пресс-клещи (кабели x2 быстрее) · 4 рация ·
  5 каска · 6 мультиметр · 7 напарник.
- **Звук**: сирены при старте смены и приёмке, шуруповёрт, шаги, лязг лестницы,
  тревожное тиканье. Кнопка 🔊 в HUD, состояние сохраняется.
- Рекорд хранится в `localStorage`.

## Структура

```

├── index.html   — разметка, HUD с таймером, оверлей, экранные кнопки
├── style.css    — оформление, адаптив, тревожная подсветка
├── game.js      — движок: объекты, кабели, босс, звук (Web Audio), 2.5D-свет
└── serve.ps1    — локальный статический сервер для разработки
```
