# Монтажник АПС

2D-аркада про монтажника пожарной сигнализации. Смена за сменой он лазает по лестницам
строящегося бизнес-центра, ставит извещатели, сирены и приборы, зарабатывает очки,
а с каждым уровнем открывает новые инструменты и способности.

## Запуск

Игра — один статический сайт без сборки и зависимостей.

```powershell
# из папки aps-game
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Открой <http://127.0.0.1:8123/>. Можно и просто открыть `index.html` двойным кликом —
всё работает с файловой системы.

## Управление

| Действие | Клавиши |
| --- | --- |
| Ходить | `←` `→` или `A` `D` |
| Лестницы | `↑` `↓` или `W` `S` |
| Установить оборудование | `Пробел` или `E` |
| Следующая смена | `Enter` |
| Начать заново | `R` |

На телефоне появляются экранные кнопки.

## Геймплей

- На каждом этаже висят точки монтажа (пунктирный квадрат). Подойди и нажми «Пробел».
- Устройства дают очки; серия быстрых установок повышает множитель комбо (до x2).
- Смена закрывается, когда установлено всё по заданию: 5 устройств на 1-м уровне,
  дальше +2 за уровень.
- Между сменами открываются функции:
  2. Шуруповёрт — установка на 45% быстрее
  3. Тепловизор — тепловые извещатели дают x2 очки
  4. Рация — комбо не сбрасывается
  5. Каска — скорость +25%
  6. Мультиметр — +10 очков за устройство
  7. Напарник — +20% очков
- Рекорд хранится в `localStorage`.

## Структура

```
aps-game/
├── index.html   — разметка, HUD, оверлей, экранные кнопки
├── style.css    — оформление и адаптив
├── game.js      — вся игра: физика, уровни, очки, отрисовка
└── serve.ps1    — локальный статический сервер для разработки
```
