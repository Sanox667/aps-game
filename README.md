# Монтажник АПС

2D-аркада про монтажника пожарной сигнализации. Курсирует по объектам, прокладывает
кабельные трассы от распаячных коробок, ставит извещатели и сирены, гонится за
дедлайном смены, а каждые пять объектов принимает генподрядчик. С уровнями
открываются новые инструменты и способности.

## Играть

**https://sanox667.github.io/aps-game/** — GitHub Pages, работает на компе и на телефоне.

Локально (для разработки):

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
# http://127.0.0.1:8123/
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Ходить | `←` `→` или `A` `D` (на телефоне — джойстик) |
| Лестницы | `↑` `↓` или `W` `S` |
| Проложить кабель | `C` или `Q` |
| Установить оборудование | `Пробел` или `E` |
| Сдать работы (приёмка) | `Пробел` у щита АПС |
| Звук вкл/выкл | `M` |
| Следующий объект | `Enter` |
| Начать заново | `R` |

На телефоне вместо стрелок — **джойстик**: тапни по сцене и веди пальцем
(влево/вправо — бег, вверх/вниз — лестницы). Кнопки «Кабель» и «Ставить» —
справа. Кнопка ⛶ разворачивает игру во весь экран (на Android — сразу
альбомный полноэкранный режим).

## Геймплей

- **Кабели — базовая механика.** Устройство нельзя смонтировать, пока от распаячной
  коробки этажа к точке монтажа не проложена светящаяся трасса. За кабель тоже
  начисляются очки.
- **Дедлайн смены.** У каждого объекта своё время. Полоска в HUD; последние 10 секунд —
  красный пульс и тиканье. Просрочка: −40 очков, комбо в ноль, сердитый генподрядчик.
- **Объекты идут по кругу из 10 сцен** с ростом сложности: БЦ «Заря» → Школа №14
  (темно) → Склад «Гранит» (5 этажей, ящики) → ТЦ «Меридиан» → Стадион «Факел» (босс) →
  Больница «Надежда» → Офис «Синева» → Завод «Прогресс» → Аэропорт «Крыло» →
  Энергоблок «Аврора» (босс). Со 2-го круга каждого объекта таймеры короче,
  босс быстрее и ловит дальше, штраф поимки растёт.
- **Босс «Генподрядчик» каждые 5 объектов.** Патрулирует этажи с планшетом, ловит
  вас: −15 очков и стан. Финал — приёмка: гонка к щиту АПС. Доехал первым: −30;
  вы сдали раньше: +130.
- **Комбо** за быстрые установки — множитель до x2. Рация из 4-й смены делает комбо
  несгораемым.
- **Разблокировки**: 2 шуруповёрт · 3 пресс-клещи (кабели x2 быстрее) · 4 рация ·
  5 каска · 6 мультиметр · 7 напарник.
- **Звук**: сирены при старте смены и приёмке, шуруповёрт, шаги, лязг лестницы,
  тревожное тиканье. Кнопка 🔊 в HUD, состояние сохраняется.
- Рекорд хранится в `localStorage`.

## Выбор монтажника (бета-2)

Перед сменой и по кнопке 👤 в HUD — экран выбора. Цифры `1`–`6` или клик.

| Персонаж | Удача | Особенность |
| --- | --- | --- |
| ⚡ Соль | 30% | Офигенно быстрый монтаж, половина — БРАК, переделывать |
| 🧓 Илюша | 70% | 95 лет стажа: медленно (как в первый раз), но честно |
| 🦑 Кальмар | 90% | Медленно, зато качественно и красиво |
| 🚿 Дима который Игорь | 50% | Очень медленный сантехник; промазал — ставит кран (+2) |
| 😤 Володя | 60% | На босс-объекте с шансом 60% сдаёт приёмку без монтажа |
| 👷 Шавкат | 55% | Бригадир: 30% призвать 5 узбеков, работают весь объект |

Плюс общий слой для всех:
- **Помехи** каждые ~20–30 с: сорвана поставка гофры (кабели ×3 медленнее),
  мокрые полы (падение ×3, скорость ниже), блэкаут (видно только рядом).
- **Улучшения** — коробки на этажах: 💨 турбо-ботинки, 🔩 съёмный патрон
  (монтаж ×2 быстрее), ×2 двойная смена, 🛡 щит комбо. Живут 12 с.
- **Падения с лестниц**: у каждого монтажника свой шанс свалиться при захвате
  лестницы (стан 1.2 с, комбо сгорает).

## Начальник Ленин

На каждом объекте периодически появляется **Ленин**: гуляет по этажам с
планшетом. Подойдёт близко — зовёт на перекур, и монтажник **вынужден бежать
к нему** и курить пару секунд, пока срок смены тикает. Некурить нельзя,
убежать можно — тогда Ильич подождёт 9 с и уйдёт не попыхав.

## Структура

```
aps-game/
├── index.html   — разметка, HUD с таймером, оверлей, экранные кнопки
├── style.css    — оформление, адаптив, тревожная подсветка
├── game.js      — движок: объекты, кабели, босс, персонажи, звук (Web Audio), 2.5D-свет
├── serve.ps1    — локальный статический сервер для разработки
└── android/     — Capacitor-обёртка для APK (сборка через junction C:\apsbuild)
```
